# Manuals library

Manuals here are indexed automatically for the manual search (RAG) in the app.
Supported: `.md`, `.txt`, `.pdf`.

Put the brand (first), model and article number on a line starting with `models:` near the top
(for Markdown, inside an HTML comment), e.g. `models: IKEA, MALM, 403.604.65`.
When the photo's OCR finds one of them, the app opens this manual automatically.

Mark test files that are not official manufacturer documents as such in the first line.
